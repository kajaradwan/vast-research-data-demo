VAST Catalog

What is on disk, by lab and by file type, as a SQL table. VAST refreshes it from snapshots; it is often never queried.

VAST DB

Tables that live next to the files, under the same access rules, queried from Trino, Spark or Python.

S3

A drop zone for instruments, collaborators and cloud tools, on the same files your NFS users see.

Snapshots

Freeze a cohort or a paper’s inputs, files and tables together, so a result can be reproduced.

Protocol audit

“Who read sample X?” answered from a table, with the identity and protocol: every read that reaches storage.

How to read what follows

Real system, lab scale, nothing hidden

A shared lab cluster running 5.5.0-sp6, using only capabilities present in 5.4.3 per its API and source (not run on 5.4.3 here). Trino 478 here; 475 pairs with 5.4.

The trigger, its events and the broker are DataEngine’s own. The function runs as a stand-in consumer calling the same handler(ctx, event), because no Kubernetes cluster is linked.

Every timing is from a shared lab cluster and one client. None is a performance claim.

Public, open-licence data only: 1000 Genomes 30x, ONT open data, ATLAS 13 TeV Open Data (CC0).

The rapidity-mass matrix, scored by an autoencoder

RMM per event
MET + 10 jets + 10 b-jets + 5 μ + 5 e + 5 γ. ET, mT and masses scaled by √s; rapidity terms by C = 0.15.

inputs
36² − 9: the nine invariant masses you bin in are left out, to limit sculpting of the search masses, as in the ATLAS search.

1287-800-400-200 and back, leaky ReLU, MSE loss: trained once, offline, on 210k tt̄ events, 5 min on CPU.


ln(MSE)
score
Reconstruction loss per event, numpy only in the function. A toy model: its cuts are not ATLAS’s.




◆Data: ATLAS 13 TeV Open Data 2020, 1-lepton (CC0). SM tt̄ to train and test; Z′→tt̄ at 12 masses from 0.4 to 3 TeV as the “anomaly”.








Backup · what the toy shows, and what it doesn’t
A pipeline demo, not a physics result




Separation grows with Z′ mass
AUC, held-out SM tt̄ vs Z′→tt̄, by Z′ mass (GeV). 0.5 is chance.


What it actually ranks
In every mjb bin it puts hard, high-mass Z′ first: of the 72 Z′ in the 0–200 GeV top 100, 62 are ≥ 1.5 TeV. That looks like enrichment only where a bin has room (live set: 28.5% → 72%).
Against a tt̄-only background with all 12 Z′ masses injected together, the top-1% cut lowers cross-section-weighted purity (6.2% → 4.5%): bookkeeping, not sensitivity.
ATLAS trained on data. We trained on tt̄ MC to grade with truth, so a cut set on MC selects 0.13% of real data, not 1%.
